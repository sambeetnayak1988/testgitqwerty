# testgitqwerty

A simple practice repository containing HTML/CSS samples, including:

- Product invoice templates
- A sample static website with multiple pages

## Static Website Pages

The sample static website includes:

- `index.html` (Home)
- `about.html` (About)
- `contact.html` (Contact)
- `terms-and-conditions.html` (Terms and Conditions)
- `styles.css` (Shared styles)

## How to Run

No build tools are required.

1. Open `index.html` directly in your browser.
2. Use the top navigation links to move between pages.

## Notes

- This is a static frontend-only example.
- The contact form is UI-only and does not submit data to a backend.
